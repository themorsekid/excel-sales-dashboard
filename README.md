# excel-sales-dashboard

## Project Context
This dashboard was created as part of a Data Analyst training module focusing on Excel data cleaning, descriptive statistics, and interactive Pivot Table design.

## Key Requirements Completed
- Cleaned and prepared global sales transaction data.
- Built Pivot Tables and visualizations for Total Revenue, Sales by Category, Yearly Trends, and Customer Segments.
- Designed an interactive dashboard with dynamic KPI cards and synced Slicers.
